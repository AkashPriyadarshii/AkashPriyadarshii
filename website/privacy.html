( 01 // ZERO DATA COLLECTION )

This website is delivered as static HTML, CSS, and vanilla JavaScript hosted on GitHub Pages. It does not employ Google Analytics, Meta Pixels, cookies, session recording scripts, or third-party fingerprinting. No personal data, IP logs, or device telemetry is collected, stored, or sold by Akash Priyadarshi.

( 02 // OFFLINE-FIRST PHILOSOPHY )

The software tools built by Akash (including financial utilities like kharcha and exam engines like neet-cbt) are designed from the ground up to be offline-first:

  • Financial transaction logs remain encrypted in local on-device SQLite databases.
  • No financial or personal SMS parsing happens on remote servers.
  • Systems CLIs (rustygrep, zcat, repomap) run strictly on local compute environments with zero network outbound telemetry.

( 03 // OPEN LLM & AGENT ACCESS )

All technical documentation and project details are explicitly exposed to AI agents, researchers, and automated crawlers via robots.txt, llms.txt, and the Model Context Protocol manifest. Knowledge is meant to be indexed, parsed, and cited freely.

( 04 // CONTACT REGARDING PRIVACY )

For any questions regarding security architecture or data isolation across any open-source tool, open an issue on the respective GitHub repository.
